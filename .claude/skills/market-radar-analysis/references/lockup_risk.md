# 解禁风险

## 为什么重要

短线最容易被忽略的地雷之一：一只股票叙事再好、板块再强，如果30天内有大比例限售股解禁，主力减持的压力会让你拿不住。

解禁不是基本面分析，是短线直接风险。

---

## 什么情况需要警惕

**高风险标志**（建议在 risk_note 中写明）：
- 解禁规模 ≥ 当前流通市值的 10%，且距今 ≤ 30 天
- 解禁方是 PE/VC（上市前的财务投资者），减持意愿最强
- 股价已经相对解禁成本有较大溢价（>2倍），减持动力更强

**中性情况**：
- 解禁方是战略投资者或产业资本，减持意愿通常低于财务投资者
- 解禁规模小（< 5% 流通市值），影响有限

**可忽略情况**：
- 解禁日距今 > 60 天（短线持仓窗口之外）
- 已经历过大规模解禁，剩余解禁比例很小

---

## 如何使用

数据来自 `lockup_expiry` 表（`fetcher/eastmoney.py` 的 `fetch_lockup_expiry`）。

对每只 T0/T1 候选股，查一下近30天内有没有解禁记录。如果有：

1. 在 `risk_note` 里写明：`"30天内有解禁：XX万股（PE机构，占流通市值8%）"`
2. 如果风险较高，考虑将评级从 T0 降为 T1，或从 T1 降为 T2
3. 不要因为解禁就把股票从名单里删掉——用户可能已经知道，让他们自己判断

---

## 简单查询方式

```bash
python agent/query.py lockup --code 300XXX
```

（如果 query.py 还没有这个命令，可以直接用 Bash 查数据库）
