# DT Pool V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an experimental `dt_pool_v2` pipeline that runs beside the existing `dt_pool` pipeline and shows a second "实验跌停" KPI on the realtime dashboard.

**Architecture:** Keep the current AkShare-based `dt_pool` unchanged. Add a second fetch path that scrapes the Eastmoney `dtgc` detail page, stores rows in a new `dt_pool_v2` table, exposes `/api/dt-pool-v2`, and renders the count beside the current "今日跌停" KPI for side-by-side comparison.

**Tech Stack:** Python, Flask, SQLite, requests/regex parsing, React, TypeScript, unittest

def fetch_dt_pool_v2() -> None:
    trade_date = date.today().strftime("%Y-%m-%d")
    html = requests.get(EASTMONEY_DT_URL, headers=..., timeout=20).text
    rows = _parse_dt_pool_v2_rows(html)
