# DT Pool V3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a third跌停 pipeline, `dt_pool_v3`, computed from QMT realtime ticks using the project's own limit-down price rules, and show its count as a `QMT跌停` KPI on the realtime dashboard.

**Architecture:** Keep `dt_pool` and `dt_pool_v2` unchanged. Reuse the existing QMT connection and A-share universe fetch flow from `fetcher/xtquant_breadth.py`, compute `down_limit` per stock using the same board/ST rules as `quant/loader.py`, persist the current snapshot into `dt_pool_v3`, expose `/api/dt-pool-v3`, and render a third KPI beside the existing跌停 cards.

**Tech Stack:** Python, Flask, SQLite, xtquant, React, TypeScript, unittest
